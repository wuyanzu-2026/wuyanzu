恢复白包14列、B包全类型15列、客服非会话操作、原有新增/编辑/素材表单、原统计列顺序、趋势开关及导航。仅本次新增项标绿色“新增”；宽表横向滚动，字段清单和跳转按钮为审阅工具。开发必须先读交付文档“零、开发必须遵守”。

## 打开方式

- 产品审阅：使用浏览器打开 `index.html`。
- 开发交付：使用浏览器打开 `开发交付文档.html`，含需求、数据口径、TopOn接入约束、源码位置、建议接口和31条开发验收用例；支持打印。
- 两个HTML都是单文件，样式/脚本内嵌，不依赖CDN、安装依赖、构建步骤或真实业务服务。彼此的相对链接仅用于便捷切换，复制单个HTML也可阅读本身内容。

## 建议审阅路径

1. 首页为白包APP，原有字段与操作完整保留。通过侧栏新增“收益与投放报表”入口：筛选2026-11-15、计步示例、印度，查看消耗100美元、收益120美元、差额20美元、收益/消耗120%。
2. 点击“投放明细”，查看Meta60美元及Google Ads40美元；渠道不分摊收益。修改消耗后验证汇总变化。
3. 点击“录入投放数据”，试验必填、非负金额、非负整数安装数和同维度重复校验。
4. 白包APP → 计步示例 → 广告数据：切换自建广告/TopOn、广告位、时/日/周/月，查看活跃去重和人均。
5. B包管理 → 广告数据：选择全部对应白包或单个白包，验证分母范围。
6. 白包/B包删除：先取消，再确认；删除仅作用于本地演示，历史报表保留。
7. Telegram机器人 → 客服管理：查看移除会话字段后的列表和规则，编辑当日上限。
8. 底部“随机下发演示”：模拟请求一次/100次，低价和不匹配地区素材不命中。

## 状态与规则联动

- 底部场景支持正常、加载、空数据、查询失败、未就绪、零展示、零活跃/异常、只读。
- 如需演示提交失败，先勾选“下次提交失败”，再打开录入、编辑或删除弹窗提交；重试可成功。
- 点击左侧R编号定位右侧规则，点击右侧规则卡片可自动打开对应页面或弹窗并高亮；共21条。
- 所有数据均为模拟；刷新或“重置演示”恢复初始状态。不使用真实登录、密钥、广告或生产写入。

## 统计口径

- 展示/人均：UTC+5:30，人均=当前范围展示次数÷对应白包同周期活跃人数。
- 收益/投放：UTC+0、USD，日期+白包+国家汇总，人工录入渠道/消耗/安装，TopOn收益仅模拟自动同步。
- 缺失不等于0，收益未完整或消耗未录入时不计算完整收支结果。

# 白包广告数据统计补充版 · V3.0

日期：2026-11-13。打开index.html即可离线查看；开发阅读需求文档.html，编辑源为需求文档.md。

本次仅白包菜单：白包列表 → 广告数据弹窗。上午已上线的独立投放统计不再纳入本次原型或开发范围。没有独立管理入口、页面、演示切换或新增开发章节。

## 核心行为

- 白包自身安装用户、日活在列表展示；弹窗只查看关联投放的广告数据。
- 选择应用拉活：金额与付费人数（总/老/新），一列显示5/3/2。
- 选择客服建联：建联人数（总/老/新），一列显示5/3/2。
- 当前白包归属范围内计数；首次事实与新老/去重规则复用已上线能力。
- 未关联白包只提示空态，不回退全局。

## 走查

1. 默认白包甲，拉活投放人数5/3/2；弹窗没有白包自身数据。
2. 切换关联客服投放，单列建联5/3/2，付费/安装列消失。
3. 底部切换白包乙，同一拉活关联项为5/2/3。
4. 切换白包丙，只有暂无关联提示；关闭后列表可看安装用户/日活。
5. 修改时间、粒度、广告位，检查去重与错误/零值/未就绪状态。

交接整个文件夹并保留相对位置；所有数据本地模拟。独立投放统计的已上线业务与生产配置未改动。

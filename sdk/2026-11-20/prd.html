01 · 本统计批范围与发布边界

【本次更新】统计批独立交付，不依赖配置批先上线

本目录只交付 B 包广告数据独立页面、维度筛选、人数转化率和历史兼容。B 包列表“广告数据”入口的页面化改造由本统计批负责。配置批原型已移除该入口，不是本批功能被取消，也不是要求删除现网旧入口。

分类内容边界
本批 · P0原广告数据弹窗改为独立页面保留单条 B 包上下文、原指标、日期、时间粒度、广告位和趋势。
本批 · P0TG 状态与安装维度组合筛选基于历史事件快照；未知不能按未安装或非当日安装处理。
本批 · P0点击率与建联率统一按人数计算，同一范围去重后重算，分母为零显示“—”。
本批 · P0数据接收与兼容新增事件时间、TG 快照、白包安装时间的贯通；旧 SDK 与历史缺失走未知规则。
不在本批白包开关、B 包克隆、客服组、跳转绑定、注册回调不改其配置，不以其上线为依赖。使用现有 B 包标识和现有授权。
保持原样白包数据/TopOn、首页、经营收益、注册事件不把本统计批口径自动推广到其他旧报表或注册链路。

本批内部需要后台前端、服务端查询/聚合、SDK 事件字段与测试共同完成。两批的发布顺序和具体时间由排期确定，不能把“独立排期”误解为不需要本批内部联调。

02 · 用户流程与页面结构

目标用户为电脑端后台运营人员，需要区分 TG 安装状态和新安装用户，查看 B 包广告展示、点击和建联效果。

  1. 01B 包列表点击单条“广告数据”
  2. 02进入独立页面，显示当前投放名称、类型和关联白包
  3. 03设置日期、TG、安装维度及广告位，提交查询
  4. 04同批结果更新指标、明细、转化率和趋势
  5. 05切换时/日/周/月或返回 B 包列表
区域要求
页头标识当前 B 包，提供返回列表。切换投放后不得串用上一投放数据。
条件区保留时间范围与广告位；新增 TG 状态、安装维度。
指标区原有指标低亮保留，点击率和建联率高亮标识本次新增。
明细与趋势保留原有明细和趋势；时/日/周/月一致聚合，可查看原有各广告位。
B 包列表上下文仅突出“广告数据”入口；编辑、克隆、素材等不是本统计批交互。
其他导航原型只保留导航，不展开未修改页面；不表示正式后台功能删除。

03 · DS-01 筛选条件

字段类型与选项默认 / 校验应用范围
当前 B 包沿用现有投放标识由入口携带，服务端验证可访问范围所有查询限定该投放。
开始 / 结束日期日期范围默认沿用现有页面；开始不得晚于结束指标、明细和趋势。
时间粒度时 / 日 / 周 / 月沿用原交互；原型默认日先筛选，再按所选粒度聚合。
广告位开屏 / Banner / 插屏 / 激励，多选沿用原选择能力；至少选择一个广告位指标、明细和趋势一致。
TG 安装状态全部 / 已安装 TG / 未安装 TG默认全部按广告事件时快照判断，不读当前设备状态反推。
安装维度全部 / 当日安装 / 非当日安装默认全部按真实白包安装日与对应广告事件日比较。
  • 日期统一沿用平台时间印度时间 UTC+5:30，安装时间与事件时间先转换到同一日期口径再比较。
  • “当日”不是运营点击查询的当天，也不是整个范围的开始日。跨日区间先逐事件比较，再聚合。
  • 查询和重置应对全部数据区域生效；条件修改但尚未提交时，不得把旧结果标成已应用新条件。
  • 原型演示窗口 2026-11-17～2026-11-19 不是固定的上线默认时间范围，也不是服务端查询边界。
  • 本批不擅自新增最大查询天数、未知筛选选项或另一个权限范围。
对应规则

R-019～R-022。原有默认日期和时间粒度行为沿用现网，不以模拟数据替代正式默认值。

04 · DS-02 指标、去重与转化率

指标业务定义结果处理
点击率点击人数 ÷ 展示人数以百分比展示；展示人数为零时显示“—”。
建联率建联人数 ÷ 点击人数以百分比展示；点击人数为零时显示“—”。
人数同一筛选范围内按既有用户唯一标识去重汇总时整体去重，不把每日或每广告位人数直接相加。
人均展示次数展示次数 ÷ 展示人数保留现有指标；分母为零时保持无值语义。
展示 / 点击 / 分配次数与人数保留当前统计明细的对应次数、人数不能把次数填入本次新增的人数转化率分子或分母。
建联总 / 新 / 老沿用既有建联含义与归因逻辑“新建联”不等于“当日安装”，不得借新筛选重定义。
应用拉活类型沿用其原有安装、付费等指标不涉及建联的类型显示“—”，不把不适用显示为真实零转化。

计算示例

展示人数点击人数建联人数点击率建联率
2416416 ÷ 24 ≈ 66.7%4 ÷ 16 = 25.0%
  • 两个比率必须使用同一 B 包、日期范围、广告位、TG 和安装维度下的人数。不能先算每行百分比再平均。
  • 原型以一位小数表达百分比；正式展示精度统一沿用报表规范，验收先核对原始人数与比值。
  • 真实用户去重标识、跨白包场景的既有口径需开发核对并在联调记录中明确；不得临时拿机器人账号数、注册次数或数据行数当人数。
对应规则

R-023～R-025。原有指标保留，不因新增转化率删掉次数、人数、建联新老或人均展示。

05 · DS-03 历史未知数据兼容

缺失的 TG 状态和安装时间分别作为未知处理，不增加“未知”筛选项。某一维度缺失，不表示其他维度也不可用。

数据情况筛选应否纳入
TG 状态未知TG＝全部保留，其他筛选条件继续判断。
TG 状态未知TG＝已安装或未安装排除；不能默认算未安装。
安装时间未知安装维度＝全部保留，其他筛选条件继续判断。
安装时间未知安装维度＝当日或非当日排除；不能默认算非当日。
TG 已知、安装时间未知指定 TG，安装＝全部只要 TG 符合条件则保留。
某维度未知且被具体值排除组合条件指标、明细、趋势和比率同步排除，不能仅过滤表格。
  • “全部”保留未知历史，指定条件只包含该维度已知且匹配的数据。不要为了让分组合计等于全部而强行归类。
  • 页面提示：“部分历史数据缺少维度，筛选结果仅包含可识别数据。”若当前全部查询包含未知，应同时说明全部保留未知，避免误读。
  • 只允许用可信历史证据补齐；不能用用户当前 TG 状态反推过去，也不能将设备首次入库日期当真实安装日期。
  • 不删除原历史记录，不把未知改写成 false、0 或一个伪造安装日期。
对应规则

R-022、R-026。历史可补齐多少需要核查，缺失时如何显示和筛选已经确定，不应等待数据核查后再临时定义规则。

06 · DS-04 事件快照与新旧 SDK

逻辑字段需要表达的信息兼容要求
事件时间广告事件实际发生时间跨日离线补报仍按原事件时间，不按接收时间改写。
TG 安装状态快照事件时已安装 / 未安装 / 无法确认旧 SDK 未传或无法判定时为未知，不能默认未安装。
白包安装时间当前展示广告的白包真实安装时间不是 B 包安装回调时间，不是服务器首次看到设备的时间。
B 包、广告位与用户关联沿用现有投放、广告及设备/用户标识查询权限、投放归属和人数去重口径保持一致。
建联等后续事件关联关联广告或点击的历史快照TG 筛选沿关联快照，不查询用户当前 TG 状态；缺失关联快照按未知处理。
  • SDK 在事件产生时记录快照，离线排队和失败重试不能重采并覆盖原值。
  • 例如事件在平台日期 2026-11-19 发生、2026-11-20 才补报，不能因晚到就变成 11 月 20 日的原始广告事件。
  • 跨日建联的原统计日期、归因窗口及新老定义继续沿现有报表；本批不以新增维度为由重写建联业务。联调须覆盖晚到与跨日关联。
  • 缺少新增字段的旧 SDK 事件走未知兼容；新旧 SDK 共存时查询仍应可用。
  • 本地源码中 SDK 已发送广告事件 timestamp，但后端原接收 DTO 未接该字段；需核对真实部署版本并贯通接收、存储与查询。
实现边界

本 PRD 规定逻辑数据语义，不将演示 JSON 的字段名当正式接口协议。具体字段名、时间单位、存储及索引由开发在技术评审中明确，并保持上述结果。

07 · DS-05 页面状态、权限与文案

场景界面要求数据要求
首次进入 / 查询中加载状态，查询提交防重复不得将旧投放或旧条件结果误标为本次新结果。
查询成功同步显示指标、明细、趋势及两项比率全部采用同一已应用筛选条件。
空结果当前条件下暂无数据，可调整条件不伪造数据；相关分母为零则显示“—”。
查询失败保留条件并提供重试错误不表示真实零数据；重试仍使用原条件。
日期或广告位无效对应错误提示，阻止无效提交不发送口径不明的查询。
缺少历史维度可见的兼容说明不隐藏未知存在，也不误归类。
无权访问 B 包沿用现有权限反馈前后端均限制现有数据范围，不因独立 URL 越权。
切换 B 包 / 返回列表当前投放上下文清晰不串包、不复用错误缓存或上一投放数据。

错误诊断与业务提示分开；内部标识、接口失败详情供日志排查，不直接向运营暴露敏感配置。本批不新增角色、导出、首页统计、经营收益或机器人统计模块。

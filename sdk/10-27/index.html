规则标注

点击卡片会定位到左侧对应模块
R-001

默认 AdMob，按 N 插自有广告

白包广告位默认出 AdMob。配置 N 后，每 N 次插入 1 次自有广告。

R-002

三个广告位各自计 N

开屏、Banner、激励分开配置、分开计数，互不影响。

R-003

N=0 / 1 / 5

  • 0：该位一直 AdMob
  • 1：该位一直自有广告
  • 5：每 5 次插 1 次自有
R-004

同一白包可混合投放

一个白包可同时关联多条应用拉活和客服建联。各广告位独立按 N 插入自有广告；该次自有广告从所有已关联、已启用投放的命中素材里选出价最高者。

R-005

白包只配 N 和 Adjust

白包不再选自有广告类型。客服投放仍放在 B 包管理，类型选客服建联。国家和 MCC 配在客服素材上。

R-006

一条物料可覆盖多国家/MCC

同一套图和同一个机器人可勾选多个国家、MCC。不同国家若机器人不同，必须拆成多条素材。

R-007

国家且 MCC 都要命中

设备 IP 国家在列表中，且 MCC 在列表中，才使用该客服物料。

R-008

跨类型也比出价

同一广告位，应用拉活素材和客服素材只要都命中，就一起比出价，高者下发；同价保留先配置的。

R-009

未命中回退 AdMob

该位无物料，或国家/MCC 未命中，本次回退 AdMob。

R-010

测试设备跳过定向和频次

标记测试设备后，忽略国家、MCC、USB 调试和频次，直接看出价最高的自有广告。

R-011

停用投放保留数据

停用某条投放后，该投放停止出广告，历史数据和白包关联都保留。白包不再有「切换自有广告类型」。

R-012

客服物料校验

广告类型、素材、跳转 URL、国家、MCC 必填。跳转必须是 https://t.me/机器人用户名，不能带 ?start=，不能填私人号或 WhatsApp。

R-013

功能权限沿用现网模块

角色继续勾选菜单和操作。白包配置走白包权限，客服素材走物料权限。数据范围不配在角色上。

R-014

看板口径

展示/点击统计自有广告（B 包+客服）。付费只统计应用拉活，建联只统计客服建联。

R-015

保存反馈

成功提示并刷新列表；失败不关闭弹窗。

R-016

关联即投放

投放关联了启用中的白包即可投放，不再校验白包类型。未关联或白包禁用则未投放。

R-017

Adjust 全套事件都保留

同一白包可同时产生 B 包安装/付费和客服建联。Token、注册、付费、首充、B包安装、建联 Key 都要配齐。

R-018

广告数据沿用现网

白包和投放都可看广告数据。切到客服建联投放后，顶部指标、表格和趋势只显示展示、点击、建联。

R-019

设备详情与测试标记

设备列表可复制 GAID、查看详情、标记测试设备。测试设备跳过定向和频次。

R-020

账户增加投放数据范围

沿用现网账户/角色页。角色下增加全部投放或指定投放。指定后只能看这些投放及其关联白包、素材、设备、看板。

R-021

B包安装事件Key留在白包

与 Adjust Token、注册/付费/首充/建联一起配置。有应用拉活转化时照常打 B 包安装。

R-022

现网筛选与分页

设备可按时间范围筛选。列表支持 10/20/50 条每页。国家和 MCC 可搜索勾选，沿用现网全量名单。

R-023

客服统计展示/点击/建联

投放类型为客服建联时，看板、投放列表、素材列表和广告数据都只看展示、点击、建联。建联=用户在对应国家机器人里点击「立即联系」，不是点了广告，也不是打开 Telegram。应用拉活仍统计安装、展示、点击、付费。

R-024

跳转只填国家机器人

素材跳转到 https://t.me/机器人。客服号由该机器人自己分配。中台后台不管号池。

R-025

白包增加建联事件Key

客服建联 S2S 使用白包 Adjust 的建联 Event Token，不要复用首充或付费。

R-026

B 包子账户只看授权投放

  • 数据范围挂在账户，不挂在角色
  • 可授权应用拉活和客服建联投放
  • 看板、白包指标、素材、设备都按授权过滤
  • 子账户不能新增投放，也不能改白包 N/Adjust
  • 未授权 ID 直接提示无权限

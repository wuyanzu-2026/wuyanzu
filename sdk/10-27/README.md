## 最终口径

- 白包不再选自有广告类型
- 同一白包可同时关联多条应用拉活和客服建联
- 各广告位独立按 N 插入自有广告，命中素材跨类型比出价
- 客服跳转只填 `https://t.me/国家机器人`
- 建联 = 用户在机器人点「立即联系」
- 号池只在 Telegram 机器人里，不在中台
- 白包同时保留付费类事件 Key 和建联事件 Key
- 账户可指定 B 包/投放数据范围，子账户只能看对应投放的相关数据
- 机器人用户语文案按 Telegram 环境语言自动切换，未覆盖用英文
- 占用 click_id 不调 connect；成功/重复走 HTTP 200；粘性回访不加计数、不清 connected；B7 分到离班号也告警；库失败不读兜底号；管理员和超级管理员拆两份配置

# AdControl 后台变更页面交互原型 v5.3

## 打开方式

直接双击同目录下的 `index.html`。使用原生 HTML、CSS、JavaScript，无需安装依赖、启动服务或联网。

左侧仅展开白包APP、B包管理、其他客服组和B包广告数据，右侧为 26 条规则标注。其余六个未改动页面只保留低亮导航，不可点击进入；不表示正式后台删除这些功能。变更页面内现有功能低亮但可操作，新增/调整功能高亮。功能范围见 `后台功能对照.md`。

点击左侧编号查看规则，点击右侧规则卡片会打开并定位到对应页面或弹窗。顶部“演示场景”用于切换失败、超时、权限不足、空数据等状态。“全宽查看”可暂时收起规则栏；宽表在内部横向滚动，原有列和右侧操作均保留。

## 建议查看顺序

1. 白包 APP → 编辑：修改某广告位的次数和间隔，关闭后重新开启检查数值保留；保存，再进入编辑点击“模拟 SDK 拉取”，查看已保存版本。
2. B 包管理 → 编辑客服建联：查看 TG 机器人与其他客服组的单选绑定，以及存量地址迁移示意。
3. 其他客服组：新增、编辑地址；查看分配预览；尝试删除被投放引用的组，检查删除保护。
4. B 包管理 → 克隆：客服建联直接创建停用副本；应用拉活填写不重复的新包名后创建。查看副本素材与统计，确认素材独立、历史统计为零。
5. 顶部演示场景 → 克隆失败/超时：再次操作克隆，查看完整回滚与结果核查。切换“指定投放账户”查看创建限制。
6. B 包管理 → 广告数据：默认有数据的演示日期为 2026-11-17 至 2026-11-19，可组合 TG 状态、当日安装、日期与广告位筛选；切换时/日/周/月，查看指标、明细和趋势同步变化。

## 演示边界

- 全部数据均为模拟数据，仅在当前页面内存中保存；刷新或点击“重置演示”恢复初始状态。
- 不连接测试后台，不发送真实注册事件，不访问客服地址，不修改业务源码。
- 按本轮指示，白包新增/编辑不再展示 B 包注册接收地址、复制入口或配套说明；原有注册事件Key仍保留。
- 白包注册与 B 包注册独立；原型保留这一边界，不模拟取消或合并任一事件。
- 注册回调的 URL、归因、校验、去重、重试等技术建议仍保留联调标记，详见 `注册事件回传-源码核查.md`。
- 历史缺失维度为“未知”，不会自动归类成未安装 TG或非当日安装；页面有兼容说明，筛选逻辑使用模拟历史事件快照。
- 原型为桌面端，已检查 1280、1440、1920 像素宽度。较宽明细表在表格内部横向滚动，页面与规则栏分别纵向滚动。

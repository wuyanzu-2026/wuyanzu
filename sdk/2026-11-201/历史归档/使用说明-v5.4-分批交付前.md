# 配置类原型：使用说明 v5.4

本目录现在只维护白包广告位独立开关、B 包克隆、其他客服组和机器人/客服组绑定。数据统计改版已独立拆分到 ../2026-11-20-B包广告数据统计/。

直接打开 index.html。仅展开白包APP、B包管理、其他客服组三个配置页面；其余导航保留但不进入。变更页面内原有字段、列和操作低亮保留，新增或调整功能高亮。右侧为本项目的 18 条规则。

## 建议操作

1. 白包APP → 编辑：独立控制四个广告位，验证关闭后保留次数和间隔；保存后可用原型辅助的“模拟 SDK 拉取”查看已保存配置。
2. B包管理 → 编辑客服建联：选择已有机器人及其他客服组。
3. 其他客服组：维护组内地址、查看随机分配预览、验证引用删除保护。
4. B包管理 → 克隆：客服建联直接克隆，应用拉活填写不重复的新包名；副本默认停用、素材独立、历史统计为零。
5. 顶部演示场景可验证克隆失败、超时核查和创建权限。
6. 原“广告数据”入口保留，点击会打开独立统计原型；不在本目录重复绘制统计改版。

数据仅保存在当前页面内存中。不会修改测试后台或业务源码。B 包注册接收地址区块继续按先前要求不展示，原有注册事件Key保留。

原白包数据/TopOn和素材管理等相关上下文功能保留，它们不属于本次新增的 B 包统计改版。历史合并版计划在“历史归档”中保留，仅供追溯，不作为当前实施范围。

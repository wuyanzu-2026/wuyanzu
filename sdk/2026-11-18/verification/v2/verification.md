## 已检查

- 统计：各 App 独立展示，已安装 + 未安装 = 安装总人数，占比正确，零用户显示“—”。
- 配置归属：白包不再显示统一跳转页签或地址输入，原有渠道、事件及 TG 统计保留；B 包提供国家和对应投放类型的跳转设置。
- 国家：搜索、多选、取消单项、清空均有效；空选择可保存为全球；B 包列表、全部已有素材和新建素材同步继承；取消不改变已保存范围。
- 隔离：修改一个 B 包不影响关联相同白包的其他 B 包；同一 B 包的不同来源白包共用其地址。
- 地址：两组可增删；客服建联两组均为空、应用拉活唯一地址为空，均可保存；任意文本可保存并回读。
- 类型切换：其他 → TG 机器人清空已安装组，仅余一个空框；未安装组保留；取消还原，保存后保留新配置。
- 分配：每次点击产生新请求；对应组多条随机、单条固定；不跨组兜底。
- 事件：未安装 TG 的客服建联跳转触发 `app_click_wa`；已安装 TG、应用拉活、空地址及请求失败不触发；检测未知与历史未上报按未安装处理。
- 原有配置：保留原有事件字段，不增加后台 `app_click_wa` 事件 Key。
- 素材：新增、编辑均无独立国家和地址输入，国家只读继承，保留素材、广告类型、出价和状态；查看统一配置定位所属 B 包，无来源白包选择器；编辑取消可返回素材列表。
- 规则：13 个唯一编号，逐项验证右侧到左侧定位，弹窗打开时优先定位弹窗内目标；国家规则左侧编号可定位右侧；无重复 HTML ID、无孤立编号。
- 静态资源：HTML 引用的 CSS、JavaScript、计划文件均存在；无 CDN、远程字体、网络调用或未完成占位文字；JavaScript 语法检查通过。
- 视觉：检查实际桌面浏览器视口。配置弹窗内部滚动，国家选择器与地址输入可操作，右侧规则独立滚动；操作列固定，表格次要字段可横向滚动。

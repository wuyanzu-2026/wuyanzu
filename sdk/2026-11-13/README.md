## 打开方式

1. 双击 `index.html` 查看交互原型。可直接离线打开，不需要安装依赖。
2. 打开 `需求文档.html` 阅读／打印需求，或编辑源文件 `需求文档.md`。
3. 将本文件夹整体交给开发，保留 HTML、CSS、JS 的相对位置。

## 核心业务口径

- 应用拉活：新增一列「付费人数（总/老/新）」；显示 `10/5/5`；保留原付费金额，不显示建联。
- 客服建联：原建联列改为一列「建联人数（总/老/新）」；显示 `10/5/5`。
- 当前 B 包独立，以用户首次付费／首次建联判断新老。
- 每个统计周期内按用户去重；同一行新老互斥，总=老+新。
- 周／月从用户集合重新去重；首次判定不随日期或广告位筛选重置。

## 交接边界

原型所有数据均为本地模拟，未连接生产，不包含账号密码。模拟事件账本仅用于解释规则，不是正式后台新增用户明细功能。

主列表、全局概览、白包报表、配置、SDK、Adjust 回传规则不在本次改动范围。文档第4.4节和第7.3节列出了开发必须核验的用户标识、付费归属映射和历史首次覆盖范围；不能以金额或事件记录数直接代替去重人数。

文件说明：`prototype.css` 为原型样式，`prototype.js` 为本地模拟交互。原型的状态选择和B包切换为演示工具，不要求正式后台增加这些控件。
